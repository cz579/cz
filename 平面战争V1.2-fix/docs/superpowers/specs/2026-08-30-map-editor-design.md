# 平面战争V1.1 地图编辑器

日期：2026-08-30  
状态：待实现

## 目标

在现有对战界面上增加编辑模式，让玩家绘制地形、摆城市、摆开局部队和建筑（机场、要塞），把多张自定义地图存在本机，并在人机、热座、联机开局时选用。

## 非目标（第一版不做）

- 油漆桶、左右镜像、中立城市
- 导出/导入地图文件
- 从编辑器内直接开打
- 教程页（`新手教程.html`）里的编辑器
- 随机图 / 固定地图的开局金钱仍固定为各方 1000，菜单不另加金钱项
- 预装运输船货物、护卫队、残血、已行动状态

## 入口与界面

1. 主菜单「新游戏」下方增加「地图编辑器」。
2. 进入后隐藏 `#menu`，显示 `#game-screen`，`game.editor = true`。仍跑现有渲染循环，但不结束回合、不跑 AI、不处理征召购买。结束回合、未行动、对战存档等按钮隐藏或禁用。
3. 顶栏改为编辑器工具条：地图名（可改）、尺寸、载入、保存、另存、返回菜单。
4. 右侧面板改为笔刷栏：阵营（蓝/红）、地形、城市、单位、机场、要塞、开局金钱。
5. 棋盘沿用现有画布、镜头、拖动、滚轮缩放。窗口拉伸（1600×900 铺满）继续作用在整个 `#app` 上。
6. 新游戏页在固定地图下方增加「自定义地图」列表。选中后仍选对战方式、阵营、回合范围，再开始战役。
7. 返回菜单时若有未保存修改，先确认再离开。

## 结构

| 文件 | 职责 |
|------|------|
| `editor.js` | 编辑状态、笔刷、载入源、保存列表、校验文案。模式与 `tutorial.js` 相同：读 `game.js` 全局函数。 |
| `index.html` | 主菜单按钮、自定义地图列表容器、编辑器顶栏/侧栏所需节点（可复用 `#game-screen` 并在编辑模式下改内容）。 |
| `style.css` | 编辑器笔刷、选中态、顶栏字段。 |
| `game.js` | `newGame` 接受自定义蓝图；点击在 `game.editor` 时交给编辑器；序列化已包含地形/单位/建筑，联机无需新协议。 |

教程页不引入 `editor.js`。

## 地图数据

本机键：`planeWar_v08_maps`。值为数组，最多 20 张。超出时拒绝新「另存」，提示删一张或覆盖。

每张地图：

```json
{
  "v": 1,
  "id": "字符串唯一 id",
  "name": "显示名",
  "updatedAt": 0,
  "sizeKey": "small|normal|large|huge|plains|strait|mountains|woods|isles",
  "w": 55,
  "h": 50,
  "money": { "player": 1000, "ai": 1000 },
  "terrain": [0],
  "cities": [{ "x": 0, "y": 0, "owner": "player" }],
  "units": [{ "type": "line", "owner": "player", "x": 0, "y": 0, "parked": false }],
  "buildings": [{ "type": "airport", "owner": "player", "x": 0, "y": 0 }]
}
```

- `owner` 只有 `player`（蓝）和 `ai`（红）。
- `terrain` 为长度 `w*h` 的整数数组，取值与现有 `TERRAIN` 一致。
- `money.player` / `money.ai` 为整数，范围 0–99999，缺省 1000。
- 空军：所在格为己方机场或航空母舰则为停场（`parked: true`），否则飞行。
- 不存金钱消耗、回合、HP、护卫、上船。开局满血、未行动。

## 载入源

| 来源 | 结果 |
|------|------|
| 空白 | 四档尺寸之一（小 45×40、普通 55×50、大 65×60、超大 75×60）。全平地，无城无兵无建筑。金钱 1000/1000。 |
| 固定地图 | 调用现有 `buildScenarioTerrain` + `loadScenarioCities`。无预放单位。 |
| 随机图 | 现有 `placeCities` + `generateTerrain`，可选海洋。无预放单位。 |
| 已存自定义图 | 完整恢复地形、城市、单位、建筑、金钱。 |

载入覆盖当前未保存编辑前须确认。

## 笔刷

- **阵营**：蓝 / 红，作用于随后摆的城市、单位、建筑。
- **地形**：平地、森林、丘陵、山峰、道路、隧道、海洋。笔刷直径 1 或 3（3×3）。涂到有城市的格子时该格仍强制平地并保留城市。若新地形让该格上的单位或建筑不再合法（例如海洋盖住地面部队、山峰盖住要塞），则移除这些单位/建筑。
- **城市**：在当前阵营下点格放置；一格一座；该格地形改为平地；若有建筑则先去掉建筑。
- **单位**：商店现有全部兵种。左键按阵营放置。编辑器内海军、地面单位均不要求控制区（控制区由城市和要塞在开打后按现有规则生成）。
- **机场**：非城市平地，一格一座建筑。
- **要塞**：非山峰、非海洋、非城市、无其它建筑。不要求控制区。周围 3×3 在游戏中按现有规则成为该方控制区。同一格最多驻 2 个地面单位。

操作：左键涂当前笔刷；右键清除——地形变回平地；城市/单位/建筑删除。拖动平移、滚轮缩放与对战相同。

放置合法性（编辑时立即拒绝并 toast）：

- 地面单位：不可在海洋或山峰；该格地面容量未满（`groundCapacity`：默认 1，要塞 2）。
- 海军：仅 `navyCanStand` 为真的格子（海洋，或 `cityTouchesOcean` 的沿海城市，含斜角）。不要求控制区。
- 空军：任意非越界格；若目标为己方机场/航母且机库未满则停场，否则飞行。
- 舰船：一格一艘（与现有 `navyUnitAt` 一致）。

## 保存与开打

- 编辑中可随时保存，不要求通过开打校验（允许半成品）。
- 「另存」生成新 `id`，占用一个列表槽。
- 新游戏选自定义图后，人机 / 热座 / 联机均可开打。
- 开打前硬校验，失败则 toast 原因、不进入战役：

  1. 蓝、红各至少 1 座城市。
  2. 城市格为平地。
  3. 一格至多一座城、一座建筑。
  4. 地面单位不在海洋/山峰，且不超过格子容量。
  5. 海军在 `navyCanStand` 格子上（海洋或沿海城市，含斜角）。
  6. 飞行中的空军距离最近己方机场或航母不超过 20 格；停场空军必须在己方机场或航母上且未超机库容量。
  7. 机场在非城平地。
  8. 要塞不在山峰、海洋、城市或其它建筑上。
  9. 宽高与 `terrain` 长度一致。

## 开局规则

`newGame` 增加 `opts.customMap`（上述蓝图）。存在时：

- 使用蓝图的 `w/h/terrain/cities/units/buildings`。
- `game.money` 取蓝图 `money`（钳制到 0–99999），各方独立。
- `game.withOcean`：地形中是否存在海洋格。
- `game.sizeKey`：`"custom"`；显示名用地图 `name`。
- 预放单位：`justDeployed = false`，`moved/acted = false`，攻击次数为兵种满值，满血。预放不扣开局金钱。
- 预放建筑：满血，类型仅 `airport` 与 `fortress`。
- 若蓝图含任何单位或建筑，且菜单起始回合未填写，则 `startTurn = 1`（跳过第 0 回合准备阶段）。菜单填写了起始/结束回合时仍以填写为准。
- 无单位且无建筑时，未填起始回合则仍为第 0 回合。
- 随机图与固定地图行为不变（各方 1000 元，无预放）。

第 1 回合开局时沿用现有 `newGame`：发放城市收入并 `beginTurn`。预放单位可立即移动/攻击。

## 联机

不改房间协议。房主用自定义图调用 `newGame` 后 `netPush` 现有 `serializeGame()`（已含地形、城市、单位、建筑、金钱、回合）。加入方拉房间快照即可，不必持有那份 `planeWar_v08_maps` 条目。

## 错误处理

- `localStorage` 写失败：toast「保存失败」，不丢当前编辑内存。
- 列表损坏：当作空列表，不崩溃。
- 载入缺字段：金钱回 1000，未知兵种/建筑跳过并 toast 摘要。
- 联机加入方收到的快照按现有存档应用逻辑，与自定义图来源无关。

## 测试

1. 空白小图：刷地形、摆双方城市、保存、新游戏人机开打，地形与城市一致。
2. 预放步兵与机场飞机：未填起始回合则从第 1 回合开始，单位当回合可行动，金钱为编辑器设定值。
3. 只摆城不摆兵：第 0 回合准备阶段，金钱为设定值。
4. 缺一方城市：不能开打。
5. 要塞内 2 个地面单位合法；第 3 个拒绝。飞行空军超出 20 格拒绝开打。
6. 载入「中央海峡」再改一格海洋，保存后热座开打可见修改。
7. 联机：房主自定义图，加入方看到相同地形、单位、金钱。
8. 未保存返回：确认框；取消则留在编辑器。
9. 窗口拉伸后编辑器顶栏、笔刷、棋盘一起缩放，点击格子仍对准。
10. 教程页不受影响。

## Key Decisions

- 编辑器是对战棋盘上的模式（`game.editor`），不是独立页面；复用绘制、镜头、窗口拉伸。
- 自定义图存本机列表（最多 20 张），新游戏里选用；联机只靠房主快照，不改协议。
- 预放免费、可立刻行动；有单位或建筑且未填起始回合时从第 1 回合开打。
- 开局金钱写在地图上，蓝红独立，0–99999。
- 保存允许半成品；开打才做硬校验。
